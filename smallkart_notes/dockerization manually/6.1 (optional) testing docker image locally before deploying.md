this can happen only after you have built the image using [[6-Building Docker Image]]
run 

``` bash
docker run -d --name smallkart-app -p 8080:8080 hashcodes7/smallkart_customer:latest
```
![[Pasted image 20260815160706.png]]

note- if you use open in browser it will open :8080 port but we have made apis for our app so remove 8080 and enter the api 
eg 
`whatever whatever.github.dev/hello`
and you should see the app running
![[Pasted image 20260815162252.png]]

use this command in github codespaces terminal to check logs
``` bash
docker logs -f smallkart-app
```

output will be like this 
![[Pasted image 20260815160916.png]]


this will make a container in whichever machine you are running (codespace or ur own pc)
after testing you can delete the container so it doesnt take extra space

``` bash
docker stop smallkart-app
docker rm smallkart-app
```
